# SOURCES

Provenance for every dataset and derived artifact in this repository. Experimental vs
derived is called out explicitly. See `README.md` for the reproduction command sequence.

## Environment (reproducible)

`pyproject.toml` + `uv.lock` define the environment (replaces the former conda `dev`). The **core**
group (numpy/pandas/scipy/scikit-learn/python-igraph/leidenalg/matplotlib/marimo) reproduces every
result from the shipped caches with **no GPU**: `uv sync` then `uv run python <script>`. Optional
groups: `--extra embed` (torch/transformers) only to regenerate `cache/esm/*.npy`; `--extra gen`
(olga) only to regenerate the OLGA pool. The reproducibility caches are committed via **git-lfs**
(`.gitattributes`): `cache/esm/*.npy` (public-cohort ESM-2 embeddings; **TCRvdb embeddings excluded —
derived from private data**) and `results/struct_desc_*.tsv` (predicted-structure interface
descriptors — cannot be regenerated without aldan3 + tcren).
